AirPlay Studio — WOW-игры для иностранных языков

Откройте AirPlay-Studio.html в браузере. Установка не требуется.
1. Выберите механику.
2. Выберите иностранный язык и уровень CEFR, добавьте лексику и грамматику.
3. Настройте оформление и управление.
4. Скопируйте промпт или скачайте ZIP-комплект для внешнего генератора сайтов.

Конструктор не включает камеру и не генерирует игру сам. Он создаёт подробный промпт.
Сохранение проекта: JSON-файл и локальное хранилище браузера. Не полагайтесь только на хранилище: сохраняйте файл проекта.
Для GitHub Pages переименуйте AirPlay-Studio.html в index.html и загрузите в свой репозиторий.
